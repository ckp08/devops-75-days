IP Address - unique numeric label assigned to every device connected to a computer network.

IPv4 (Traditional): Written as four blocks of numbers separated by dots (e.g., 142.250.190.46).

IPv6 (Modern): Written as a longer string of letters and numbers separated by colons (e.g., 2001:db8::ff00:42).


ip addr ==> ip a → displays loopbacks and virtual machine address (ip)

ex -
lo interface -> Loopback - 127.0.0.1
enp0s3 interface -> ip4v Address - 10.0.2.15
ipv6 - ff...

ping localhost ==> ping 127.0.0.1 → both test your computer’s internal loopback connection

************************

private IPs - local/resuable/managed by local router (via DHCP)
Starts with 192.168.x.x, 10.x.x.x, or 172.16.x.x.

Public IPs - global / Unique / Provided by ISP (airtel etc)
Any number outside the private ranges (e.g., 8.8.8.8).

Ports - A port is a virtual no (from 0 to 65535) than an OS uses to route incoming internet traffic to a specific application or service.

TCP (Transmission Control Protocol)
- used in Web Browsing (HTTPS) / SMTP (Emails) /  Fil Transfers (SFTP), SSH
- Connection -oriented (follows 3-way handshake) / guarantees no packet loss / maintains order of data

UDP (User Datagram Protocol)
Used in gaming / Video Calls / VoIP
- all opposite to TCP

PING

ping - check if a server or device is online and reachable over the network or not.

ping google.com → checks ICMP reachability and measures round-trip response and gives the IP address of the site.

ping -c 4 google.com → limits the reply to 4 lines

**************************

CURL (client url) - transfer data to or from a network server.

curl https://google.com → displays the raw HTML onto your screen for the mentioned site.

curl -I https://google.com → Shows only the server status, like 200 OK or 404 Not Found.

curl -v https://google.com → shows the exact step-by-step connection process behind the scenes.

it prints the TCP handshake, the TLS/SSL encryption exchange, the HTTP request headers sent, and the HTTP response headers received

**************************

LISTENING PORTS

sudo ss -tulpn → displays all network ports that are actively listening for connections on your Linux machine, along with the exact application names and Process IDs (PIDs) using them.

ss - socket statistics
-t (TCP): Shows TCP sockets
-u (UDP): Shows UDP sockets
-l (Listening): Filters out active connections and only shows ports waiting for incoming traffic.

-p (Processes): Lists the name of the software and its PID running the port (requires sudo).

-n (Numeric): Forces the output to show raw numbers (e.g., 22)

SSH - Secured Shell, used to securely log into and manage a remote Linux server, operates on Port 22.

ssh username@remote_host_ip → log into a remote server after successful authentication

sudo apt install openssh-server → installs ssh server


dpkg -l | grep openssh → checks if openssh-client and openssh-server are installed

sudo systemctl status ssh → verifies if ssh service is running.

sudo systemctl start sshd → starts the ssh server on port 22 to listen for active connections.

sudo systemctl stop ssh → stops the ssh server from listening active connections.

sudo systemctl restart ssh → restarts the ssh server
ssh-keygen → prompts us to generate private and public keys

********************************
SYSTEMD

- systemd is the system and service manager for modern Linux operating systems
- As PID 1 (Process ID 1), it is the very first process that the Linux kernel starts.
- it has two primary command line interface
 systemctl (controls the service) and journalctl(reads the logs)

*********************************
JOURNALCTL

- systemctl manages actions and services, while journalctl manages the logs generated by those services

sudo journalctl -u ssh → displays all the log entries generated exclusively by the SSH service

sudo journalctl -u ssh -f →  keeps the terminal open and prints new login entries the millisecond they occur.
